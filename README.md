# Audiobook Reader

A personal application that synchronizes an audiobook with its corresponding
PDF/EPUB book so that the user can listen to the audiobook while reading the
book.

## Goal

The application will provide:

- Audiobook playback
- PDF/EPUB reading
- Synchronized text highlighting
- Audio position ↔ book position synchronization
- Playback controls
- Reading progress
- Bookmarks
- Local-first book processing

## Project Status

🚧 Early development

## Planned Architecture

- Frontend: Web-based reader and audio player
- Backend: Book/audio processing and synchronization
- Database: To be decided
- Docker: Development and supporting services
- Synchronization: Timestamp/text based alignment
